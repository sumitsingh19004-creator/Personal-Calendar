# 📅 Personal Calendar

A beginner-friendly Python project using the `calendar` and `datetime` modules.

## Features

- 📅 Show year calendar
- 🗓️ Show month calendar
- ☀️ Find Sundays
- 🏖️ Find weekends
- 🎂 Find the day of your birthday
- 📆 Calculate date difference
